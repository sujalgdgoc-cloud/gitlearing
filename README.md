# 🚀 Flutter App — Email Validator & Modern Home Screen

A Flutter project that includes an elegant UI, basic authentication validation, and a visually appealing home screen.  
Built for learning and showcasing Flutter UI + form handling skills.

---

## ✨ Features

- 🧠 **Email & Password Validator** — Checks for valid email format and non-empty passwords.  
- 🎨 **Beautiful Home Screen** — Designed with clean layout, responsive widgets, and modern color schemes.  
- ⚡ **Smooth Navigation** — Seamless transition between login and home pages.  
- 📱 **Flutter UI Principles** — Uses Column, Row, Padding, and other layout widgets effectively.  

---

## 🧩 Tech Stack

- **Framework:** Flutter  
- **Language:** Dart  
- **State Management:** setState (for now)  
- **IDE:** Visual Studio Code / Android Studio  
- **Platform:** Android, iOS, Web, and Windows (coming soon)

---

## 🧠 Learning Goals

- Understand form validation in Flutter.  
- Design responsive, good-looking UIs using Flutter widgets.  
- Practice navigation and screen organization.
